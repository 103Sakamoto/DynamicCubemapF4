# Publishing

Repository: https://github.com/103Sakamoto/DynamicCubemapF4

Build from the accepted public tree, run RUN_TESTS.cmd, then PACKAGE.cmd. Review the resulting source, version metadata, default settings, licenses and both archives. Push a normal fast-forward commit, tag v1.5 at that commit and upload DynamicCubemapF4-1.5.zip, DynamicCubemapF4-1.5-source.zip and SHA256SUMS-1.5.txt to the public release. Never overwrite an existing release tag or public asset.

Publish only project source and aggregated validation. Game executables, generated native-code fixtures, private logs, captures, saves and credentials do not belong in the repository or release packages.
