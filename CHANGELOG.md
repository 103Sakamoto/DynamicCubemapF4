# Changelog

## 1.5 - 2026-10-13

- Improved performance while keeping the same reflection resolution and quality.
- Improved background reflection colors so they blend better with the sky and surroundings, outdoors and indoors.
- Restored sharper reflections during rain.
- Reflection sharpness now follows the game's materials and weather. The manual sharpness presets have been removed.
- Improved compatibility with supported Fallout 4 versions and Addictol 1.7.0.
- Added optional performance graphs and reflection previews for troubleshooting.
- Diagnostics and "Reproject reflections while moving" are now off by default.

Existing MCM settings are kept. If you previously enabled diagnostics or reprojection, turn them off in MCM if desired.

When updating, replace both the DLL and MCM files, then restart the game.

## 1.4

- Added five reflection sharpness presets.
- Fixed enabling the mod after starting the game with it disabled.
- Improved performance and added optional diagnostic logging.

Developer details for 1.5 are in [docs/CHANGELOG-TECHNICAL.md](docs/CHANGELOG-TECHNICAL.md).
